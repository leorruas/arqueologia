# Futuras refatorações

Este arquivo registra mudanças planejadas que ainda não devem ser apresentadas como recursos públicos do projeto.

## Referências dentro dos artigos

Objetivo futuro: tornar visível, dentro de cada estudo publicado, a base documental usada para sustentar afirmações históricas e teóricas.

A implementação deve evitar uma bibliografia genérica no fim do texto. A preferência é aproximar fonte e afirmação, distinguindo pelo menos:

- fonte histórica ou primária para data, autoria, produto, contexto e difusão;
- fonte sobre o artefato para reconstrução de decisões e usos;
- fonte teórica para conceitos empregados na interpretação;
- referência usada apenas como apoio comparativo ou hipótese.

Antes de publicar essa camada, revisar os estudos existentes para eliminar referências decorativas, fontes que não sustentam a afirmação associada e citações bibliográficas herdadas por proximidade temática.

A publicação só deve anunciar essa prática quando houver cobertura suficiente no acervo para que a promessa seja verdadeira de forma consistente.

## Auditoria editorial contínua

Manter auditoria de sentence case, headings, wikilinks, status editorial e procedência conceitual. A automação pode apontar candidatos, mas não deve rebaixar nomes próprios, marcas, produtos, siglas ou títulos oficiais para minúsculas automaticamente.
